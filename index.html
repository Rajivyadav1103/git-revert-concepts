git revert command

The git revert command is used to undo changes

It creates a new commit that undoes the changes made by a previous commit.

To use the git revert command, you need to specify the commit hash of the commit you want to revert. For example:

git revert <commit-hash>

This will create a new commit that undoes the changes made by the specified commit. You can then push the changes to the remote repository if needed.

Command Description
git revert <commit-hash> Reverts the changes made by the specified commit.
git revert --no-commit <commit-hash> Reverts the changes made by the specified commit without creating a new commit. You can then review the changes and commit them manually.
